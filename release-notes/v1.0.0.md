## 🔎 SpotDesk для Windows 1.0.0

**Скачать:** `SpotDesk-1.0.0-win64.zip` ниже (или постоянная ссылка `SpotDesk-win64.zip`). Распакуйте и запустите `SpotDesk.exe` — значок появится у часов, поиск открывается по Alt+Space.

### Что нового
- Первый выпуск: строка поиска по Alt+Space посередине экрана, как Spotlight в macOS
- Программы из меню «Пуск», с рабочего стола и из Microsoft Store — с нечётким поиском и учётом того, что вы открываете чаще
- Файлы и папки: свой быстрый индекс имён, обновляется сам; по желанию — индекс всего диска NTFS
- Калькулятор: «2+2*2», «sqrt 16», «15% от 3000» — ответ первой строкой, Enter копирует
- Курсы валют ЦБ РФ: «100 usd в rub», «50 евро в рублях», «курс юаня»
- Светлая и тёмная тема, плавное появление, всё управляется с клавиатуры

### Подробнее
- Клавиши: ↑↓ — выбор, Enter — открыть, Ctrl+Enter — показать в папке, Shift+Enter — от имени администратора, Tab — дополнить, Esc — спрятать.
- Индекс файлов строится в фоне с низким приоритетом и следит за изменениями через уведомления Windows — без опросов диска. Папки и исключения настраиваются во вкладке «Файлы».
- Быстрый индекс NTFS (журнал USN) читает весь диск за секунды; работает, когда SpotDesk запущен от имени администратора, иначе используется обычный индекс.
- Не нашлось — последняя строка ищет в Яндексе, Google, DuckDuckGo или Bing.
- Программы Nikolini (PeekDesk, SnapDesk, WinterDesk) всегда находятся по имени.
- Горячая клавиша меняется в настройках; если Alt+Space занято (например, PowerToys Run), SpotDesk предупредит и предложит Ctrl+Space.
- Запускается вместе с Windows (выключается в настройках). В простое не тратит процессор. Каждая функция включается отдельно.
- В сеть — только проверка обновлений на GitHub и курсы ЦБ РФ, когда вы пересчитываете валюту. Без рекламы и без слежки.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
