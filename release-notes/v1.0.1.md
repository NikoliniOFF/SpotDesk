## 🔎 SpotDesk для Windows 1.0.1

**Скачать:** `SpotDesk-1.0.1-win64.zip` ниже (или постоянная ссылка `SpotDesk-win64.zip`). Распакуйте и запустите `SpotDesk.exe`. Если SpotDesk уже установлен, он сам предложит обновиться.

### Что нового
- Новый значок в общем стиле программ Nikolini: монитор, строка поиска и стеклянная лупа
- «О программе» → «Другие программы от Nikolini»: HubDesk первым, добавлены DockDesk и IslandDesk
- Список программ и их значки подтягиваются с сайтов сами — новые программы появятся без обновления SpotDesk
- Без интернета — встроенный список и значки
- Проверка обновлений больше не обращается к api.github.com (чтобы не упираться в лимит запросов)

### Подробнее
- Список программ загружается только когда открыта вкладка «О программе» (не чаще раза в 12 часов) и вместе с проверкой обновлений; хранится в `%LOCALAPPDATA%\SpotDesk`. В простое SpotDesk по-прежнему ничего не делает.
- Новые версии: адрес последнего выпуска берётся из редиректа GitHub (`/releases/latest`), файлы — с `/releases/download/v…`. При сбое сети или ответе 403/429 программа молча попробует позже.
- Поиск, калькулятор, курсы валют и настройки — без изменений.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
