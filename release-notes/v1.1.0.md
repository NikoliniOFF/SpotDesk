## 🔎 SpotDesk для Windows 1.1.0

**Скачать:** `SpotDesk-1.1.0-win64.zip` ниже (или постоянная ссылка `SpotDesk-win64.zip`). Распакуйте и запустите `SpotDesk.exe`. Если SpotDesk уже установлен, он сам предложит обновиться.

### Что нового
- Полупрозрачный фон (акрил) теперь работает: в Windows 11 — настоящий акрил, в Windows 10 — размытие
- Перевод единиц: «5 км в милях», «30c to f», «10 фунтов в кг», «1 гб в мб», «100 км/ч»
- Даты и время: «дней до нового года», «через 100 дней», «время в токио», «сегодня»
- Команды: «блокировка», «сон», «перезагрузка», «выключить», «очистить корзину» — опасные спрашивают подтверждение
- Параметры Windows по слову: «bluetooth», «экран», «wi-fi», «звук», «обновления»
- Быстрый поиск: «g …» — Google, «я …» — Яндекс, «yt …» — YouTube, «вики …» — Википедия

### Подробнее
- **Акрил.** Раньше Windows просто не включала его для окна без заголовка, поэтому фон оставался сплошным. Теперь окно поиска устроено так, как Windows ожидает, а на Windows 10 и ранних сборках Windows 11 используется размытие. Если в Windows выключены «Эффекты прозрачности» (Параметры → Персонализация → Цвета), фон остаётся сплошным, как у самой Windows. Переключатель — «Настройки → Общие → Полупрозрачный фон». С акрилом панель появляется без плавного проявления (так устроена Windows).
- **Единицы** — длина, вес, температура, площадь (в том числе сотки и гектары), объём, скорость, размеры файлов и время. Можно писать по-русски и по-английски. Enter копирует ответ.
- **Время в городах** — больше 70 городов и стран (Москва, Екатеринбург, Новосибирск, Владивосток, Минск, Алматы, Ташкент, Стамбул, Дубай, Лондон, Берлин, Нью-Йорк, Токио и другие). Считается по часовым поясам Windows, без интернета, с разницей «на 6 ч больше, чем у вас».
- **Команды** перезагрузки, выключения, выхода из учётной записи и очистки корзины выполняются только после второго нажатия Enter (Esc — отмена).
- У каждой новой функции свой переключатель в настройках (вкладки «Поиск» и «Расчёты»). Всё работает на компьютере, ничего никуда не отправляется.
- Во «Других программах от Nikolini» — новые значки и описания (встроенная копия на случай, если нет интернета).

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
